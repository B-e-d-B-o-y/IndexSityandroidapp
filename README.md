# IndexSity Android App

**IndexSity** — это простое Android-приложение, предназначенное для получения информации о населенном пункте по его почтовому индексу. Приложение отправляет запрос к API [Zippopotam.us](https://api.zippopotam.us/) и отображает название города, а также его географические координаты (широту и долготу).

## Основные функции
* **Поиск по индексу:** Ввод 6-значного почтового индекса РФ.
* **Отображение данных:** Вывод названия города, долготы и широты.
* **Валидация:** Проверка на пустой ввод и корректность длины индекса.
* **Обработка ошибок:** Информирование пользователя, если индекс не найден или введен неверно.

## Технологии и стек
* **Язык:** Java.
* **Сетевое взаимодействие:** `HttpURLConnection`, `AsyncTask`.
* **Обработка данных:** JSON (библиотека `org.json`).
* **API:** [Zippopotam.us](https://api.zippopotam.us/).

## Как работает приложение
Пользователь вводит индекс в поле `EditText`. После нажатия кнопки приложение формирует запрос к API, получает JSON-ответ, парсит его и обновляет интерфейс пользователя, отображая полученные данные (название города, координаты) или сообщение об ошибке.
